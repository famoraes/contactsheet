# Keyboard shortcuts

The same list is in the app under **Show keyboard shortcuts** at the bottom of
the panel. Shortcuts are ignored while typing in a text field.

## Frames

| Keys | Action |
|---|---|
| ← / → / Enter | Previous / next frame |
| ⌘A | Select all frames shown |
| ⌘O | Add images |
| ⌫ | Remove selected frames (files on disk are kept) |
| ⌘E | Export |

## Adjusting

| Keys | Action |
|---|---|
| Q / A | Density + / − |
| W / S | Contrast + / − |
| E / D | Saturation + / − |
| 1 / 2 | Cyan − / + |
| 3 / 4 | Magenta − / + |
| 5 / 6 | Yellow − / + |
| ⇧ + adjust key | Step by 5 instead of 1 |
| G | Colour / grayscale |
| L | Look: normal / flat |
| N | Neutral picker (click a grey; ⇧-click a second grey) |
| R | Recalc |
| ⇧R | Roll base: analyse selected (or all) frames together |
| ⌘C / ⌘V | Copy / paste settings |
| ⇧⌘V | Paste settings and base correction |

## Crop and geometry

| Keys | Action |
|---|---|
| C | Crop mode (Enter applies, Esc cancels) |
| ⇧C | AutoCrop (selected frames, or the box in crop mode) |
| [ / ] | Rotate left / right |
| H / V | Flip horizontal / vertical |

## Viewing

| Keys | Action |
|---|---|
| Z / double-click | Zoom 100% / fit; drag or scroll to pan |
| B | Before / after (automatic conversion) |
| ⇧B | Show the negative |
| X | Show clipping |
| I | Adjust / Info panel |
| Tab | Hide / show panels (image only) |
| Esc | Leave crop mode (cancel), the neutral picker, image-only mode, or close a dialog |
